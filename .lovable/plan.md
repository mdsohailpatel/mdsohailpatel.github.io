
# 3D Portfolio Website for Mohammedsohail Patel

## Overview
A modern, immersive 3D portfolio website using React Three Fiber with a dark theme, smooth animations, and interactive elements showcasing Sohail's 6+ years of software engineering experience.

## Design Direction
- **Theme**: Dark navy/charcoal background with electric blue (#3B82F6) and cyan (#06B6D4) accents
- **Typography**: Inter for body, bold geometric headings
- **3D Elements**: Floating geometric shapes, interactive globe/particles, animated skill spheres
- **Smooth scroll-based animations** with fade-ins and parallax

## Technical Approach
- React Three Fiber (@react-three/fiber v8, @react-three/drei v9) for 3D scenes
- Framer Motion for scroll animations
- Tailwind CSS for styling
- Fully responsive (3D elements simplify on mobile)
